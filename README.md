# Maestria-tareas
Repositorio para trabajar en equipo sobre las tareas de maestría en ciencia de datos (MCD) TecNM

Sigue estas reglas para una mejor colaboración
Para crear una nueva rama desde develop (cualquier cambio):
git checkout -b feat/algoritmo-andres-ejemplo origin/develop

Para guardar cambios con un mensaje:
git add .
git commit -m "Cambios: Modificando el algoritmo para calcular..." -m "Descripcion larga (opcional)"

Para empujar cambios a Develop (Una vez terminados los cambios):
git push -u origin feat/algoritmo-andres-ejemplo 

# IMPORTANTE
1. No branchear desde Main (esta rama es intocable)
2. No hacer cambios desde develop (generar una feature branch) 
3. No mergear pull requests (Solo el admin aprueba Merge)
